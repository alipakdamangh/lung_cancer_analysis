# Lung Cancer Analysis Project

## Overview
This project analyzes lung cancer data using various machine learning models. It applies data preprocessing, visualization, and classification techniques to predict cancer presence and evaluate model performance.

## Features
- Data visualization with Seaborn and Matplotlib  
- Dimensionality reduction using PCA  
- Classification using Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, KNN, and Naive Bayes  
- Model evaluation with accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix
